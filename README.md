# GitHub Agent Lab: Java to Python

This repository contains a custom GitHub Copilot agent that converts a Java
reverse-string method into an equivalent Python function.

## Structure

```
.github/agents/java-to-python.agent.md   <- the custom agent
java/ReverseString.java                  <- original Java method
python/reverse_string.py                 <- generated by the agent
python/test_reverse_string.py            <- tests generated by the agent
```

## How to use the agent

1. Open this folder in VS Code with GitHub Copilot enabled.
2. Open Copilot Chat and choose the **java-to-python** agent from the agent dropdown.
3. Prompt: `Convert java/ReverseString.java to Python and test it.`

## Example

```
Input: hello
Output: olleh
```
